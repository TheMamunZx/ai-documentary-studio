# Documentary Editing & Timeline Assembly

## Source of truth
Use the approved storyboard for shot order and actual voiceover duration for timing. Maintain a non-destructive edit decision list (EDL) and preserve original source assets.

## Assembly order
1. Place narration and build the dialogue/story spine.
2. Adjust shot durations to actual speech.
3. Add footage/reconstructions/diagrams/maps linked to claim and shot IDs.
4. Add on-screen labels/citations and subtitles.
5. Add music, ambience, SFX, fades, and audio ducking.
6. Add transitions and controlled motion for stills; avoid repetitive slideshow effects.
7. Apply consistent color treatment without changing evidentiary meaning.
8. Export a low-resolution review cut before final render when feasible.

## Project hygiene
Use stable relative asset paths where the editor supports them. Keep project file, media, fonts/licenses, proxies, and final exports organized. Do not overwrite source files. Document missing media and offline links.

## Deliverables
Editable project, `edit_decision_list.md`, `render_profile.yaml`, review cut, and final render handoff.
