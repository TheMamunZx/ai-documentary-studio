# Visual & Character Continuity

## Continuity bible
Track recurring subject/location/object IDs and approved attributes: age range if relevant and evidence-supported, clothing/materials, silhouette, proportions, hair, color palette, architecture, geography, weather, time of day, lighting, props, and camera language.

## Rules
- Never claim an AI-generated person is a real historical individual unless the depiction is evidence-based, authorized, and clearly framed.
- Do not infer private traits or create a false photographic record.
- Reuse reference images/seed IDs only where provider terms permit.
- Keep site geography, entrances, windows, materials, and major architecture consistent across shots.
- Record intentional changes (time jump, costume change, new season) as continuity events.
- If the provider cannot preserve identity or reference consistency, use separate approved shots, diagrams, silhouettes, or cutaways rather than pretending consistency is guaranteed.

## Deliverable
`continuity_bible.md` with reference asset ID, visual lock, permitted variation, forbidden drift, and shot IDs using each key.
