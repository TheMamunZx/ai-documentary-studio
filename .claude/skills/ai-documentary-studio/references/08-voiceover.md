# Voiceover Direction & Recording QA

## Pre-production
Split narration into scene/chapter segments. Build pronunciation guide for names, acronyms, locations, foreign terms, numbers, and uncommon Hindi words. Define voice profile descriptively (language, register, pace, warmth, energy, age impression only if relevant) without imitating a real public figure.

## Recording/generation
Use a licensed narrator or a provider/voice whose usage terms allow the intended publication. Keep the same narrator settings where feasible. Save one file per segment with stable IDs, e.g. `VO_SC001_v001.wav`.

## QA
Listen or inspect every segment for pronunciation, skipped/duplicated words, pacing, clipped starts/ends, noise, clipping, silence, breath edits, and level consistency. Use actual file duration to update storyboard in/out points. Keep natural phrasing; do not time-stretch speech beyond intelligibility.

## Deliverables
`voiceover_manifest.csv`, `pronunciation_guide.md`, `voiceover_review.md`, and final narration files. Record provider, model/voice ID, generation date, license/terms note, and consent evidence where applicable. Do not store secrets.
